# 배리어 프리 맵 v3.3

배리어 프리 맵은 장소별 접근성 정보와 위험 구역을 지도에 기록하고, 운영 콘솔에서 등록 현황과 최근 변경을 확인하는 컴에듀웹 프로젝트입니다. 지도와 콘솔에서 GeoJSON을 내보내고 병합할 수 있습니다.

- [Windows 운영 콘솔](BFM_v3.3/02_개발_소스/README.md)은 Electron, Express, SQLite를 사용합니다. 별도 검증 DB에서 앱을 시연하는 순서가 포함되어 있습니다.
- [Sites 웹 버전](BFM_v3.3/05_Sites_소스/README.md)은 Leaflet 지도, 운영 콘솔, Worker API, D1 스키마를 포함합니다.
- [개발 진척도 및 로드맵](개발_진척도_및_로드맵.md)과 [프로젝트 폴더 안내](프로젝트_폴더안내.md)에서 각 버전과 확인 범위를 볼 수 있습니다.
